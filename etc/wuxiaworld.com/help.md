Install the packages required:

```
pip install grpcio-tools
```

1- To generate the proto files from typescript files, run this command:

```
1.generate_wuxia_proto.py
```

2a- To generate the wuxiacom_proto.py that contain WUXIWORLD_PROTO as dict, run this command:

```
2.dump_wuxia_json.py
```

2b- To generate the json from proto , run this command:

```
2.dump_wuxia_json.py -json
```

2c- To generate the prety print json from proto , run this command:

```
2.dump_wuxia_json.py -json-prety
```
